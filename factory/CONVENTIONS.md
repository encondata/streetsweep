# StreetSweep, for the factory's agents

Read this before you start. It's what the repo is and how it's checked.

## What's where

| Part | Path | Stack |
|---|---|---|
| Server | `v2/server/src` | Fastify 5 + TypeScript, Postgres 16/PostGIS (`pg`), pg-boss worker (`worker.ts`) |
| Database | `v2/db/migrations/NNNN_name.sql` | Applied in order on start. Append a new one; never edit one that's shipped. |
| Web | `v2/web/src` | Svelte 5 (runes) + MapLibre GL, built into the server image |
| Android | `app/` | Kotlin, Jetpack Compose, Material 3, Room, osmdroid; car screen via Android Auto |
| iPad | `v2/ios/StreetSweep` | SwiftUI + MapLibre Native, generated by `xcodegen` |
| Docs | `v2/docs/` | `PLAN.md`, `APP-API.md` (the phone/iPad contract), `FUTURE_PLANS.md` |

## How to check your work (run what your change touches)

- **Server + web** (from `v2/`): `docker compose build api 2>&1 | grep -E "svelte-check found|error TS|ERROR"`
  must show `0 errors`; then `docker compose up -d api worker` and `./scripts/smoke.sh`
  (every stage must say `all passed`). The stack serves http://localhost:8430.
  Demo login for trying things: `v2/scripts/seed-demo.mjs` (local only).
- **Android** (repo root): `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew :app:assembleDebug :app:testDebugUnitTest -q`
- **iPad** (from `v2/ios`): `xcodegen generate && xcodebuild -project StreetSweep.xcodeproj -scheme StreetSweep -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M4)' -derivedDataPath build build -quiet`

There's one local Docker stack: building from your worktree replaces what it runs. That's fine.

## House rules

- **The server is the record.** It computes every figure; apps upload to it and show what it says.
- **Count streets, never segments.** People never see "segments" or "sections": every piece
  sharing a name is one street (`coalesce(lower(name), 'way ' || way_id)`).
- **Light UI**, no dark mode unless asked. Plain words in the UI; say what happened and what to do.
- **The repo is public.** No secrets, keys, passwords or personal data in code, tests or docs.
- Comments say *why*, in plain sentences, at the density of the code around them.
  Match the surrounding naming and idiom.
- New API fields the apps use go in `v2/docs/APP-API.md`.
- Commit messages: a one-line summary, a blank line, a short body, then
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
